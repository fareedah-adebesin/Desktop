Here you can find little details about HTML and CSS:


HTML
CSS
HTML means HyperText Markup Language.
It is used for simple texts on a website
without any style or interactivity.
It has several attributes and tags, some of
its tags are empty, while some are
full. Empty means they don't need a
closing tag. Full means, they need a
closing tag.
Let's move to CSS which Cascading StyleSheet.
Unlike HTML which is just simple
texts, CSS has to do with the
styling of the webpage. It involves
making the website visually appealing
instead of some texts alone.
